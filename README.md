# # Görev takip sistemi

Bu proje React ve Tailwind CSS kullanılarak geliştirilmiş basit bir görev takip uygulamasıdır.

## Özellikler

* Görev ekleme
* Görev listeleme
* Görev güncelleme
* Görev silme
* Görev tamamlandı olarak işaretleme
* Kategori seçme
* Öncelik belirleme
* LocalStorage ile verileri saklama

## Kullanılan Teknolojiler

* React
* Vite
* Tailwind CSS
* JavaScript
* LocalStorage

## Kurulum

```bash
npm install
npm run dev
```

## Proje Görseli

Proje ekran görüntüsü raporda yer almaktadır.
